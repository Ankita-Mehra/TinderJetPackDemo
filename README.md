# TinderJetPackDemo ❤️

A **Jetpack Compose** practice project showcasing a few modern dating app screens with **API integration**.

This is **not a complete application**—it's a demo created to explore modern Android development concepts, including Compose UI, Material 3, navigation, state management, and consuming REST APIs.

### Tech Stack

* Kotlin
* Jetpack Compose
* Material 3
* REST API Integration

> Built for learning and practicing modern Android development with Jetpack Compose.
